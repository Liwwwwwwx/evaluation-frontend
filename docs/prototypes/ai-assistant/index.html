Prototypes · 测评助手

三个方向，不是三次换皮

三版都包含「生成标准 / 回答评分」，但操作逻辑不同：方案一像对话，方案二一次只做一步，方案三像编辑一份文档。先看逻辑，颜色和细节后面再收敛。

01

对话式

把生成标准当成一段对话：题目发出去，标准作为助手的回复出现；评分则是把三项信息装进一张任务卡，提交后得到结果消息。

  • 最像常见大模型
  • 结果和过程都在同一条流里
  • 评分任务卡可能仍显重
打开原型 → 02

三步工作台

一次只显示一个步骤：题目 → 标准 → 输出。已完成的信息压成摘要，右侧常驻任务检查与操作，最后再进入评分结果。

  • 逻辑最清楚，不容易漏项
  • 适合较长的题目和标准
  • 步骤之间切换成本更高
打开原型 → 03

文档工作台

把题目、标准和输出当成一份文档来编辑，操作和状态放在右侧检查栏。生成标准时直接得到一份可审阅的标准文档。

  • 最适合逐条修改标准
  • 阅读体验最接近正式报告
  • 长文档在小屏上更依赖滚动
